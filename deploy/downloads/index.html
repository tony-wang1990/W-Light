W-Light 客户端下载

所有客户端都连接同一套服务器 API。登录页服务器地址填写 ，工单、设备、巡检、备件和附件数据会同步到同一套云端数据库。

Windows 客户端

下载真正的 Windows 安装程序，安装后从桌面或开始菜单启动 W-Light。

下载 Windows 安装包 校验 SHA256

Mac 客户端

下载 DMG 后拖入 Applications。未签名内测包首次打开可能需要右键选择“打开”。

下载 Mac DMG 使用 Web/PWA

Linux 客户端

下载 AppImage 后添加执行权限即可运行，适合 Ubuntu/Debian 运维工作站。

下载 Linux AppImage 使用 Web/PWA

Android 手机

下载 APK 后安装。首次安装如提示未知来源，请允许当前浏览器安装应用。

下载 Android APK

iPhone / iPad

正式 iOS 包需要 TestFlight、企业签名或 Ad Hoc。签名导出的 IPA 可作为内测交付物下载。

下载签名 IPA 打开 Web/PWA
下载按钮 404 表示对应安装包还没有发布到 /root/W-Light/deploy/downloads/。请先按仓库里的 DESKTOP_CLIENT_GUIDE.md 或 MOBILE_APP_GUIDE.md 打包并上传。
生产对外分发建议为 Windows 配置代码签名证书，为 macOS 配置 Apple Developer ID、公证流程；内部测试包可以先直接下载安装。
