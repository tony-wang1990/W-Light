W-Light 客户端下载

所有客户端都连接同一个服务器 API。登录页服务器地址填写 ，工单、设备、巡检、备件、附件数据会自动同步到同一套云端数据库。

Android 手机

下载 APK 后安装。首次安装如果提示未知来源，请允许当前浏览器安装。

下载 Android APK

iPhone / iPad

正式 iOS 包需要 TestFlight 或企业/Ad Hoc 签名。没有 iOS 包时，可先用 Safari 打开 Web 端并添加到主屏幕。

Windows 客户端

用 Edge 或 Chrome 打开 Web 端，点击地址栏安装图标，即可安装成桌面应用。

打开 Web/PWA

Mac 客户端

用 Chrome/Edge 安装为应用，或用 Safari 添加到 Dock。后续可扩展独立 DMG 安装包。

打开 Web/PWA
如果 APK 链接 404，说明服务器还没有发布 Android 包。请先按仓库里的 MOBILE_APP_GUIDE.md 打包并上传到 /root/W-Light/deploy/downloads/w-light-latest.apk。
